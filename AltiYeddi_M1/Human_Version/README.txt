CSC 3250 AI ESCAPE ROOM

Run with: python3 run.py

Students edit algo.py. The algorithm dropdown includes BFS, DFS, UCS, Greedy Best-First, and A*.
When you first run this you should see a sample of a map.  The map has a door and a key.  
At this point you do not need the key to unlock the door.  1st step is to get to the exit.  Do not worry about the door & key yet.
Each algorithm needs to be completed.  Please use this map to do your testing.

TIMING
The framework times only the selected search algorithm with time.perf_counter().
GUI animation time is not included. Runtime is shown in the CURRENT RUN panel.
Unimplemented algorithms still display the practice map and report their status.
